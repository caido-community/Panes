# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.4]

### Added

- Code highlighting in Markdown code blocks [#23](https://github.com/caido-community/Panes/issues/23)

### Fixed

- Panes not updating when switching requests on Caido 0.59 [#24](https://github.com/caido-community/Panes/issues/24)

## [1.0.3] - 2026-10-15

### Fixed

- Banner missing from the packaged README [#22](https://github.com/caido-community/Panes/pull/22)

## [1.0.2] - 2026-06-29

### Added

- HTTP code block language with body highlighting and folding [#18](https://github.com/caido-community/Panes/pull/18)
- Line numbers, code folding, whitespace and active line options [#18](https://github.com/caido-community/Panes/pull/18)
- JavaScript transformation type [#20](https://github.com/caido-community/Panes/pull/20)

### Changed

- README bundled in the plugin package [#19](https://github.com/caido-community/Panes/pull/19)

## [1.0.1] - 2026-02-23

### Added

- Shell selection for command transformations [#8](https://github.com/caido-community/Panes/issues/8)
- Dev mode for debugging transformations [#7](https://github.com/caido-community/Panes/issues/7)

### Fixed

- Shell config not sourced [#6](https://github.com/caido-community/Panes/issues/6)
- Code block setting not saved [#9](https://github.com/caido-community/Panes/issues/9)
- View modes not resizable [#10](https://github.com/caido-community/Panes/issues/10)
- Search not working in panes [#11](https://github.com/caido-community/Panes/issues/11)

## [1.0.0] - 2026-01-24

### Added

- Initial release
